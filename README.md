# Full-Stack Task Tracker

## Project Description
The Full-Stack Task Tracker is a simple web application that helps users organize and manage their daily tasks.

Users will be able to create, view, update, and delete tasks. The goal is to make task management simple and convenient.

## Front-End Plan
The front end is the part of the application users will see and interact with.

- Create a clean and simple user interface.
- Display a list of tasks.
- Provide a form for adding new tasks.
- Allow users to edit and delete tasks.
- Use HTML, CSS, and JavaScript.

## Back-End Plan
The back end will process requests and manage task information.

- Create an API to handle tasks.
- Save task information in a database.
- Retrieve tasks from the database.
- Allow users to create, update, and delete tasks.
- Use Node.js and Express for the server.
- Use SQLite for the database.

## Planned Features
1. Add a new task.
2. View all tasks.
3. Edit an existing task.
4. Mark a task as completed.
5. Delete a task.

## Version Control
Git will track changes made to the project files. GitHub will store the repository online and support future collaboration.
